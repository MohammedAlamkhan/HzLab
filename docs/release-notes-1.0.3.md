## HzLab 1.0.3 — Visual overhaul

This release modernises the entire visible interface without changing tuning, DSP or gesture behaviour.

### New look

- Deep navy gradient background with cyan accents and clearer information hierarchy.
- Compact top bar with the HzLab wordmark, current mode/listening state, and a round menu button.
- Five labelled bottom-navigation items: Tune, Dial, Spectra, Chords, Strobe. Tapping an item switches modes immediately.
- Settings rebuilt with rounded cards, section labels, chevrons and ripple feedback.
- New microphone-permission card.
- Refreshed dial, spectrogram, chord-grid and big-strobe layouts; the spectrogram now sits below the app header and above the bottom bar.

### Unchanged

- 52 tunings, 17 temperaments, custom editors and A4 reference.
- All advanced DSP controls and defaults introduced in 1.0.2.
- Swipe/long-press gestures, menu, and audio pipeline.

### Install

Download `HzLab-1.0.3.apk` and install it on Android 6.0 or newer. Existing 1.0.2 installs signed with the same HzLab key can update in place.

### Verification

Package: `io.github.mohammedalamkhan.hzlab`, versionCode 4. Pure Java, no native libraries, no network permission.
